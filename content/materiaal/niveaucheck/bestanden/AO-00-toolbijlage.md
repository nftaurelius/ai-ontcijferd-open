# Toolbijlage Fundament

**Peildatum: 2026-11-24.** Kijk deze bijlage na voor je de niveaucheck online zet, en pas de peildatum aan.

Het fundament heeft maar één soort tool nodig: een formulierprogramma voor de online niveaucheck. Elk programma is geschikt als het:

- per antwoord kan doorspringen naar een later deel van het formulier, of naar het einde;
- antwoorden kan ontvangen zonder dat de invuller zich aanmeldt;
- geen naam of e-mailadres hoeft te bewaren.

Twee programma's die veel organisaties al hebben. De namen van menu's en knoppen staan zoals in de Nederlandse versie, met de Engelse tussen haakjes.

## Microsoft Forms

| | |
| --- | --- |
| **Wat het is** | Formulieren en enquêtes, onderdeel van Microsoft 365 |
| **Wat het kost** | Inbegrepen bij Microsoft 365; met een gratis Microsoft-account kun je ook formulieren maken |
| **Account nodig** | Ja, voor wie het formulier maakt. Invullers niet, als je het formulier voor iedereen openzet. |
| **Secties** | Voeg een sectie toe en geef ze een titel en een beschrijving. De uitslagtekst zet je in de beschrijving. |
| **Doorspringen** | Klik bij een vraag op de knop met drie puntjes, *Meer opties*, en kies *Vertakkingen toevoegen* (*Add branching*). Op de pagina *Vertakkingsopties* kies je per antwoord naar welke latere vraag of sectie het formulier gaat, of *Einde van formulier* (*End of the form*). Bij een sectie kies je op dezelfde manier *Vertakking toevoegen*: zo zet je elke uitslagsectie op *Einde van formulier*. Je kunt alleen vooruit springen, niet terug. |
| **Anoniem** | Kies in *Instellingen*, bij *Wie kan dit formulier invullen*, voor *Iedereen kan reageren* (*Anyone can respond*). Dan is geen aanmelding nodig en worden geen namen bewaard. *Eén antwoord per persoon* werkt alleen met aanmelding: laat het uit. |
| **Bedankscherm** | In *Instellingen* kun je het bedankbericht aanpassen. |
| **Testantwoorden wissen** | Op het tabblad met de antwoorden kun je alle antwoorden verwijderen. |
| **Let op** | Organisaties kunnen *Iedereen kan reageren* uitschakelen. Zie je die keuze niet, vraag het dan aan wie jullie Microsoft 365 beheert. |
| **Officiële uitleg** | Doorspringen: https://support.microsoft.com/nl-nl/office/vertakkingslogica-gebruiken-in-microsoft-forms-16634fda-eddb-44da-856d-6a8213f0d8bb · Zonder namen: https://support.microsoft.com/nl-nl/office/instellen-dat-namen-niet-worden-vastgelegd-bij-het-verzamelen-van-antwoorden-25dd8442-f6ba-4934-9319-99f9f867f239 |

## Google Formulieren

| | |
| --- | --- |
| **Wat het is** | Formulieren en enquêtes van Google |
| **Wat het kost** | Gratis met een Google-account |
| **Account nodig** | Ja, voor wie het formulier maakt. Invullers niet, als je inloggen niet verplicht maakt. |
| **Doorspringen** | Alleen bij meerkeuzevragen en vragen met een dropdownmenu. Klik bij een vraag rechtsonder op *Meer* en kies *Ga naar sectie op basis van antwoord* (*Go to section based on answer*). Per antwoord kies je een sectie, of *Formulier versturen* (*Submit form*). Zet onder elke uitslagsectie ook "na sectie" op *Formulier versturen*. |
| **Anoniem** | Verzamel geen e-mailadressen, en beperk niet tot één antwoord: dat vraagt een aanmelding. |
| **Bedankscherm** | In de instellingen kun je het bevestigingsbericht aanpassen. |
| **Testantwoorden wissen** | Op het tabblad met de antwoorden kun je alle antwoorden verwijderen. |
| **Officiële uitleg** | https://support.google.com/docs/answer/141062?hl=nl |

## Nakijken

- [ ] Werkt het doorspringen nog zoals hierboven beschreven, en heten de menu's nog zo?
- [ ] Is het formulier ingesteld zonder verplichte aanmelding en zonder namen of e-mailadressen te verzamelen?
- [ ] Gaat het formulier na elke uitslag naar het einde?
- [ ] Zijn de testantwoorden verwijderd voor je de link deelt?
